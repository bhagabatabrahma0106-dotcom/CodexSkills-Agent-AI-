# Instagram growth agent

After installation, open this repository in a new Codex session and use:

```text
Use social-media-manager-codex for clients/<client>.
Focus on Instagram growth: relevant reach, saves, shares, profile visits,
and engaged followers. Inspect the existing client context first.
If brand inputs are missing, collect the account handle, niche, audience,
offer, voice, available assets, and realistic posting capacity.
Prepare a one-week draft plan with caption briefs, carousel or Reel concepts,
and clear CTAs. Use only verified brand facts. Track workflow status and
save all client work under that client directory. Do not publish posts.
```

## First-run inputs

- Instagram handle and a short account description
- Audience and growth objective
- Products, services, or offers, if applicable
- Brand voice, visual references, and source assets
- Posting capacity and time zone (default: Asia/Kolkata)
- Recent insights, if available: reach, saves, shares, profile visits, follows

Record supplied inputs in the ignored client context. No actual account or
analytics provider is connected by installation. Use supplied exports or a supported integration;
do not invent audience data, results, or growth guarantees.

## Use the installed specialists

- `brand-onboarding-codex`: establish brand context.
- `content-calendar-codex`: plan the weekly content mix.
- `caption-writer-codex`: write hooks, captions, and CTAs.
- `carousel-producer-codex`: build carousel stories and ordered slides.
- `motion-creative-producer-codex`: prepare short looping motion assets.
- `publisher-codex`: package approved content for publishing.
- `social-performance-review-codex`: review results and inform the next plan.

See [SCHEDULER_SETUP.md](SCHEDULER_SETUP.md) for recurring-task integration.
